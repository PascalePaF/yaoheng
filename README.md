# 曜衡 3.12

曜衡是一款黑白橙未来风格的 Windows 绿色计算与实时金融工具，提供标准/专业计算器、可伸缩历史记录、全球货币与虚拟币三端换算，以及法币和虚拟币趋势行情。

## 3.12 新增与优化

- 货币参考表在“换算数量”右侧新增可排序的“24h”列，按当前参考币种显示 `+/-` 涨跌幅，并沿用红绿底纹。
- 法币刷新时并发获取官方日频历史数据，不拖慢货币与虚拟币批量刷新。

## 3.11 新增与优化

- 货币与虚拟币 A/B/C 金额框支持直接输入加减乘除、除余和括号算式，按回车、`=` 或离开输入框后先计算再换算。
- 货币、虚拟币及两类行情趋势的参考币数额框同步支持上述基础算式。

## 3.10 新增与优化

- 任务栏、窗口标题栏、EXE 文件与应用侧栏统一使用同一个六边形曜衡 Logo。
- 任务栏身份跟随绿色版 EXE 路径，让已固定的启动按钮与运行窗口自动合并；同时通过 Windows 原生接口绑定统一 ICO 图标。

## 3.8 功能

- 货币与虚拟币参考表的收藏、置顶图标取消独立黑色底纹，直接融入当前红绿行背景。
- 货币与虚拟币参考币数额改为右对齐，趋势页参考数额同步保持右对齐。
- 货币与虚拟币趋势列表外框统一改为橙色，并在右侧加入可点击、可拖动的竖向滚动条。
- 虚拟币趋势新增“名称”列，为当前全部虚拟币提供中文名称，新上市币种也会生成清晰的中文说明标签。

## 3.7 功能

- A/B 与 B/C 之间分别提供独立交换按钮，可同时交换两端金额与币种，并立即按当前输入端重新换算。
- 三端换算提示统一使用两个等号，例如 `1 PHP = 0.1101 CNY = 0.0162 USD`。
- 参考表标题栏改为橙底黑字“搜索”，搜索框使用橙色细边框；“默认顺序”移至参考币数额左侧。
- 换算金额、币种、参考币种、参考数额、行情计价货币与市场搜索框统一使用橙色细边框。
- 收藏与置顶表头始终显示；点击“收藏”可只看收藏币种，开始搜索时会自动退出收藏筛选。
- 置顶继续采用顶部副本：副本固定在表头下，原行保留，代码、名称与换算数量排序仍可正常使用。

## 3.6 功能

- 货币与虚拟币自动刷新可分别设置分钟间隔，并可选择最小化后继续刷新。
- 关闭按钮可设置为退出应用或最小化；启动时可指定任意页面，也可记住上次页面、窗口位置和计算器模式。
- 计算器可设置默认角度制、默认标准/专业模式、历史条数、是否保留历史与复制结果格式，并新增“复制结果”按钮。
- 货币参考表移除“类型”，加入中文友好名称与洲/地区；货币和虚拟币列表在选中行时渐显收藏与置顶按钮。
- 置顶采用“顶部副本”方式，原始行仍保留在正常顺序内；排序和恢复默认顺序不会移走顶部副本。
- 货币行情增加币种名称列；货币与虚拟币行情都支持参考数额及简单四则算式，图表和换算结果会按该数额更新。
- 设置页新增缓存上限、缓存占用、清理缓存、打开应用/数据目录、迁移数据、导出/导入设置及恢复默认设置。

## 核心功能

- `%` 除余键；计算公式可在显示框内直接键盘输入，专业键盘等宽排列在标准键盘上方，切换动画可准确恢复原始位置和大小。
- 历史记录从窗口右侧独立展开；离开计算器页时自动关闭并缩回。
- 货币与虚拟币均支持 A/B/C 三端联动换算，任意一端输入后另外两端同时更新。
- 换算币种、参考币种、行情计价货币和时区统一使用实时搜索下拉，支持键盘、鼠标滚轮和拖动滚动条。
- 货币、虚拟币及行情表格支持搜索、升降序及一键恢复默认顺序。
- 货币参考表和虚拟币行情使用红绿整行底纹与黑白文字；选中行使用黑色焦点轮廓。
- 货币行情与虚拟币行情均支持币种搜索、多计价货币、参考数额和 1/7/30/90 日走势图。
- 黑夜/白天高对比度主题；刷新按钮显示带时区的完整年月日时分秒；网络状态可点击重新连接。
- 文件夹式绿色版无需安装，不使用单文件程序的系统临时解压方式。

## 项目结构

- `main.py`：程序入口。
- `app_ui.py`：桌面界面与交互逻辑。
- `calculator_core.py`：计算器核心。
- `rate_service.py`：法币、虚拟币汇率与行情服务。
- `settings_service.py`：设置与数据目录管理。
- `tests/`：自动化测试。
- `data/`：源码运行时使用的本地缓存。
- `release/曜衡/`：可直接运行的绿色版，用户设置和使用缓存也保存在这里。
- `build.ps1`：测试并重新构建绿色版。

`build/`、`__pycache__/` 等目录均为可重新生成的中间产物，不属于需要长期保留的项目文件。

## 源码运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 构建绿色版

```powershell
.\build.ps1
```

构建结果为 `release\曜衡\曜衡.exe`。分发或迁移时请复制整个 `release\曜衡` 文件夹，或使用生成的绿色免安装 ZIP。

## 测试

```powershell
python -m unittest discover -s tests -v
```

公开网络的首次连接时间由 DNS、线路和数据源决定。应用通过批量请求、持久连接和本地缓存优化体验，但不对外部网络作固定时延承诺。所有价格与汇率仅供参考，不构成交易、投资或结算建议。
