曜衡 3.14（Windows 文件夹式绿色版）
================================================

运行方法
--------
双击“曜衡.exe”即可运行，无需安装。请保留“曜衡”文件夹内的所有文件。
文件夹式绿色版适合放在 D 盘、移动硬盘或 U 盘中使用，应用数据也可以在设置中迁移到指定文件夹。
任务栏、窗口标题栏、EXE 文件和应用左上角均使用同一个六边形曜衡 Logo。
任务栏启动入口与正在运行的曜衡窗口使用同一身份，单击已运行的任务栏按钮会返回现有窗口。
货币和虚拟币的 A/B/C 金额框，以及各处参考币数额框，均支持 +、-、×、÷、%、括号；按回车、输入 = 或离开输入框即可计算。
货币参考表的换算数量右侧显示 24h 涨跌幅；正数带 +，负数带 -，并可点击表头排序。

计算器
------
标准模式为四列五行键盘，% 表示除余运算。点击左下角“专业”，标准键盘会缩小并向右下方移动，
专业函数以相同宽度和高度出现在上方；再次点击“标准”可平滑恢复初始布局。
公式显示框支持直接键盘输入或粘贴，输入过程中实时预览，按回车或直接输入“=”计算并写入历史记录。
支持科学计数法（如 1e-3）、千位分隔符、全角运算符、2π/2(3+4) 等隐式乘法；计算时会自动补齐
尚未闭合的右括号。乘除、乘方和除余后可以继续输入负数，例如 5×−2、2^−3。
按等号后继续输入运算符时会沿用内部精确结果，不会用屏幕上已缩短的小数或科学计数法文本重新计算；
大整数整除也会保留整数精度。无效千位分隔符、非十进制写法及超出范围的结果会给出明确提示。
右上角“打开历史记录”会让窗口只向右扩展；离开计算器页时历史区域自动关闭并缩回。

设置中可指定默认标准/专业模式、是否记住上次模式、DEG/RAD 角度制、历史条数、是否在重启后
保留历史，以及复制结果时使用纯数字、千位分组或“公式 = 结果”。计算器右上方可直接复制结果。

货币与虚拟币
------------
A、B、C 三个金额框均可输入，按回车或离开输入框后，另外两个金额会同时完成换算。
货币页和虚拟币页使用独立的初始数额。货币页三端选择全球法币；虚拟币页三端可自由组合
全球法币与主流虚拟币。
在 A/B 与 B/C 之间各有一个交换按钮，可分别交换对应两端的金额和币种。换算说明使用连续等号，
例如“1 PHP = 0.1101 CNY = 0.0162 USD”。

所有币种选择框均可直接输入搜索，候选项随文字实时过滤；支持上下键高亮、回车确认、鼠标点击、
滚轮选择和拖动滚动条。下拉菜单会跟随窗口移动与缩放。输入框光标在黑夜模式为白色、白天模式
为黑色，多选文字时显示浅蓝色选区。

右侧参考表拥有独立参考币种和参考币数额。数额框可输入整数、小数或仅含加减乘除与括号的算式，
输入“=”或按回车后会先求值，再按该数额换算整张表。表格支持搜索、排序和“默认顺序”。
货币表显示代码、中文名称、换算数量、24h 涨跌与地区；虚拟币表显示代码、名称、换算数量与 24h 涨跌。

“收藏”和“置顶”表头始终可见。点击“收藏”表头可只显示已收藏币种，再次点击恢复全部；在搜索框
输入任何币种时会自动退出收藏筛选。点击一行后，右侧会渐显五角星与置顶按钮；置顶会在表头下
创建一个副本，原始行仍保留在正常列表中。代码、名称、换算数量排序不会移走顶部副本。
收藏与置顶图标不再显示独立黑色底纹，而是与当前红色或绿色行背景自然融合。

换算金额框、币种框、参考币种、参考币数额和搜索框均使用橙色细边框。“搜索”为橙底黑字提示，
“默认顺序”按钮位于参考币数额左侧。

行情趋势
--------
侧栏分别提供货币行情趋势与虚拟币行情趋势。两个市场列表均支持实时搜索、每列排序和恢复默认顺序；
双击币种可查看 1、7、30、90 日趋势，鼠标移入图表可查看时点。
货币行情列表包含代码、名称、汇率和周期；计价货币使用实时搜索下拉。
虚拟币行情列表包含代码、中文名称、价格和 24h 涨跌。两个趋势列表均使用橙色外框，右侧提供
可点击、可拖动的竖向滚动条，方便快速上下浏览全部币种。
两个行情页均提供“参考数额”，支持整数、小数及简单四则算式。输入后按回车，汇率摘要和图表会按
该数额重新计算，便于查看大额兑换。

设置
----
1. 外观与时区：切换黑夜/白天；搜索所有 IANA 时区，每项同时显示 UTC 偏移与当前年月日时分秒。
2. 自动刷新：分别设置货币、虚拟币刷新间隔（分钟），并决定最小化后是否继续刷新。
3. 启动与关闭：指定默认启动页；可记住上次页面、窗口位置；关闭按钮可选退出或最小化。
4. 计算器：设置默认模式、角度制、复制格式、历史条数及历史保留方式。
5. 缓存与便携：查看缓存占用与上限，清理缓存，打开应用/数据目录，将数据或整个应用迁移到其他盘。
   清理和容量限制只处理曜衡生成的缓存，不会删除自定义数据目录中的其他文件。
6. 设置备份：导出或导入 JSON 设置文件，也可恢复默认设置。会改变数据的操作会先要求确认。
   设置保存采用原子替换并保留上一份有效备份；主设置损坏时会自动恢复。

自动刷新与最小化
----------------
启用自动刷新后，货币与虚拟币按各自分钟间隔运行。若开启“最小化后继续刷新”，窗口最小化期间
仍会按计划联网更新；关闭时选择“最小化”也会沿用同一规则。设置页提供“立即退出”用于彻底结束。

网络状态与数据源
----------------
左下角联网状态可点击重新连接。成功时为绿色，失败时为红色，只有部分数据源成功时显示橙色“部分更新”；
完整连接时间显示在下方。全部联网请求失败时会明确显示失败，并继续使用最近一次可信缓存。
法币汇率来自 ExchangeRate-API；货币历史来自 Frankfurter；虚拟币行情主要来自 Binance，
CoinGecko 作为补充或备用。应用会使用本地缓存处理短时网络不可用。

所有价格和汇率仅供参考，不构成交易、投资或结算建议。
